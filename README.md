# Online Doctor Appointment System

## Project Description

The Online Doctor Appointment System is a web-based application that allows patients to find doctors, check their availability, and book appointments online. Doctors can manage their profiles, schedules, and appointments, while administrators can manage the overall system.

## Features

- Patient Registration and Login
- Doctor Registration and Login
- Search and View Doctors
- View Doctor Specialization
- Check Doctor Availability
- Book Doctor Appointments
- View Appointment Details
- Appointment Management
- Admin Management
- User Authentication

## Technologies Used

- HTML
- CSS
- JavaScript
- Backend Technology
- Database
