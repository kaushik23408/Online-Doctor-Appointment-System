# Online Doctor Appointment System

## About the Project

The Online Doctor Appointment System is a web-based project developed to make doctor appointment booking easier and more convenient. Patients can view available doctors and book appointments online.

## Features

* Patient registration and login
* Doctor details and specialization
* Doctor availability
* Online appointment booking
* Appointment management
* Simple and user-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript
* MySQL

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Register and book an appointment.

## Objective

The main objective of this project is to provide an easy and efficient way for patients to book doctor appointments online and help manage appointments digitally.
